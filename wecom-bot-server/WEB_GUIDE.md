# Web 管理后台快速启动指南

## 🎉 恭喜！Web 管理后台已创建完成

这是一个功能完整的 **Vue 3 + Element Plus** 企业微信机器人管理后台。

## 📁 项目位置

```
<workspace>\workwx-api\wecom-bot-server\web\
```

## 🚀 快速启动（3 步）

### 步骤 1：安装依赖

```bash
cd <workspace>\workwx-api\wecom-bot-server\web
npm install
```

### 步骤 2：启动后端服务

在另一个终端启动后端：

```bash
cd <workspace>\workwx-api\wecom-bot-server
# 配置环境变量
set WECOM_BOT_WEBHOOK_KEY=your-webhook-key

# 启动后端
uvicorn wecom_bot.main:app --host 0.0.0.0 --port 8000 --reload
```

### 步骤 3：启动前端服务

```bash
cd web
npm run dev
```

访问 **http://localhost:3000** 即可看到管理后台！

## 🛠️ 开发模式

### 前后端同时开发

**终端 1 - 后端：**
```bash
cd <workspace>\workwx-api\wecom-bot-server
uvicorn wecom_bot.main:app --reload
# http://localhost:8000/docs
```

**终端 2 - 前端：**
```bash
cd <workspace>\workwx-api\wecom-bot-server\web
npm run dev
# http://localhost:3000
```

前端会自动代理 API 请求到后端（端口 8000）

## 📦 生产部署

### 方式一：Docker Compose（推荐）

```bash
# 配置环境变量
$env:WECOM_BOT_WEBHOOK_KEY="your-webhook-key"

# 一键启动前后端
docker-compose -f docker-compose.full.yml up -d

# 访问 http://localhost
```

### 方式二：分别部署

```bash
# 1. 构建前端
cd web
npm run build

# 2. 将 dist 目录部署到 Nginx
# 3. 配置 Nginx 反向代理后端 API
```

### 方式三：集成部署

将前端构建结果复制到后端静态目录：

```bash
# 构建前端
cd web && npm run build

# 复制到后端
cp -r dist/* ../wecom_bot/static/

# 后端添加静态文件路由
# 访问 http://backend:8000/
```

## ⚙️ 配置说明

### 前端配置（.env.local）

```env
VITE_API_BASE_URL=http://localhost:8000

```

### 后端配置（.env）

```env
WECOM_BOT_WEBHOOK_KEY=your-webhook-key
HOST=0.0.0.0
PORT=8000
LOG_LEVEL=INFO
```

## 🎯 使用流程

### 1. 首次使用

1. 启动后端和前端服务
2. 访问 http://localhost:3000
3. 查看控制台 - 确认连接状态
4. 进入系统设置 - 查看机器人信息
5. 发送测试消息

### 2. 发送消息

1. 点击左侧菜单 **发送消息**
2. 选择消息类型（文本/Markdown/图片/图文/卡片）
3. 填写消息内容
4. 点击 **立即发送**
5. 查看发送结果提示

### 3. 查看历史

1. 点击左侧菜单 **发送历史**
2. 使用筛选器查找记录
3. 可导出 CSV 或重发消息

## 🐛 常见问题

### Q1: 前端无法连接后端？

**检查：**
- 后端是否启动（http://localhost:8000/health）
- 跨域配置是否正确
- 防火墙是否开放端口

### Q2: WebSocket 连接失败？

**解决：**
- 确认后端 WebSocket 端点正常
- 检查浏览器控制台错误
- 尝试刷新页面

### Q3: 发送消息失败？

**检查：**
- Webhook Key 是否正确配置
- 企业微信机器人是否正常
- 查看后端日志错误信息

### Q4: 构建失败？

**尝试：**
```bash
# 清理缓存
rm -rf node_modules package-lock.json

# 重新安装
npm install

# 重新构建
npm run build
```
