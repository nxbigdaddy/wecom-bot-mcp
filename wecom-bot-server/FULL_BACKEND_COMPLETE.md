## 📊 用户管理功能详情

### 用户操作

1. **添加用户**
   - 点击「添加用户」按钮
   - 填写用户名、邮箱、手机号、密码
   - 选择角色（管理员/普通用户/访客）
   - 设置状态（启用/禁用）
   - 保存

2. **编辑用户**
   - 点击用户行的「编辑」按钮
   - 修改用户信息
   - 密码留空表示不修改
   - 保存更新

3. **启用/禁用用户**
   - 点击「启用」或「禁用」按钮
   - 确认后切换状态

4. **删除用户**
   - 点击「删除」按钮
   - 确认后删除（当前用户不可删除）

5. **搜索用户**
   - 输入用户名、邮箱或手机号
   - 实时过滤列表

6. **筛选用户**
   - 按状态筛选（启用/禁用）
   - 按角色筛选（管理员/普通用户/访客）

## 🏢 企业微信配置详情

### 配置说明

#### 1. Webhook Key 获取

**步骤：**
1. 打开企业微信 → 进入群聊
2. 点击右上角「...」→ 「群机器人」
3. 点击「添加机器人」
4. 输入名称并添加
5. 复制 Webhook 地址中的 `key` 参数

**格式：**
```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=5b76c8a6-1234-5678-9abc-def012345678
```
复制 `key=` 后面的 UUID 字符串

#### 2. 企业 ID 获取

**路径：**
企业微信管理后台 → 我的企业 → 企业信息 → 企业 ID

#### 3. 应用信息获取

**路径：**
企业微信管理后台 → 应用管理 → 选择应用 → 查看详情

- AgentId：应用 ID
- Secret：应用密钥
- EncodingAESKey：通讯录加密密钥

## 🚀 使用流程

### 快速开始

1. **配置企业微信**
   ```bash
   # 方式一：使用配置脚本
   setup.bat
   
   # 方式二：手动创建 .env 文件
   # 编辑 .env 文件，填入 Webhook Key
   ```

2. **启动服务**
   ```bash
   # 启动后端
   start.bat
   
   # 启动前端（新终端）
   cd web && npm run dev
   ```

3. **访问系统**
   - 前端：http://localhost:3001
   - 后端 API：http://localhost:8000
   - API 文档：http://localhost:8000/docs

4. **配置企业微信**
   - 访问「管理中心」→ 「企业微信配置」
   - 填写 Webhook Key
   - 点击「测试」验证配置
   - 保存配置

5. **添加用户**
   - 访问「管理中心」→ 「用户管理」
   - 点击「添加用户」
   - 填写用户信息
   - 保存

6. **发送消息**
   - 访问「发送消息」
   - 选择消息类型
   - 填写内容
   - 发送
